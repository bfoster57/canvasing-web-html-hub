## What Canvasing Is

Canvasing serves people who want a purpose-built web interface for canvassing tasks rather than a general-purpose tool. Because everything is built on plain HTML, the app loads in any standard browser and needs no desktop install.

You can work with it in two ways: launch the hosted build, or grab the repository and run it from your own machine. Either route lets you explore the application and put it to use in a web environment.

## FAQ

### How do I get to Canvasing?

Open the hosted build at [Download Latest Build](https://bfoster57.github.io/canvasing-web-html-hub/), or clone the repo and load the main HTML file from your machine.

### What does it run on?

It is a web application, so a modern browser is all it needs.

### How do I keep it current?

Either use the newest hosted build, or bring the latest changes into your local copy:

```bash
git pull
```

### Where does it keep settings?

No dedicated settings file is mentioned in the available metadata. Look through the HTML source and project assets for configuration values.

### The page will not load locally. What should I try?

Make sure you are opening the right HTML entry point, that all project files are still in their original relative locations, and that your browser is current. Serving the files through a local web server can also get around certain browser restrictions.

### Where do I ask for help?

File an issue in the project repository and include your browser, how you set the project up, and what you saw happen.
